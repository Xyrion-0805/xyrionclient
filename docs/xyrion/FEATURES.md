# 功能与当前状态

## Envelope Trigger 与 QQuad

服务端、客户端同步支持按队伍或个人触发 Quad 位置／颜色包络。`envelope_trigger_spawn pause` 在地图加载时停在起点，`envelope_trigger` 指定继续、重播、单次和循环行为；使用编辑器 Switch 层的 Envelope Trigger Team／Solo。配置与编号规则见 [ENVELOPE_QQUAD.md](ENVELOPE_QQUAD.md)。本次未运行测试或游戏内实测。

## 地图编辑器矩形 Slice

选中 Quad，在右键菜单中点击 Slice（裁剪），按住左键拖出矩形，松开生成选框内的裁剪副本。起终点作为对角顶点，其余两个顶点由 X/Y 自动补齐，四个拖动方向均可用。支持网格吸附，按住 Alt 自由定位；右键或 Esc 退出。

原 Quad 保留，裁剪副本沿用原纹理、颜色和动画轴心。选框超出原图形时只截取交集；旋转或特殊颜色插值的 Quad 可能生成多个片段，整次裁剪可一次撤销／重做。空选框不生成内容。

## Demo 剪辑工作台

Demo 播放器左上角进入工作台，支持同一源素材的多片段编排、分割裁剪、变速、撤销重做与工程保存，输出独立 Demo 片段或一个连续 MP4。用法与存储位置见 [DEMO_EDITOR.md](DEMO_EDITOR.md)，参考范围见 [OPENCUT_REFERENCE.md](OPENCUT_REFERENCE.md)。

主要入口为“设置 → Xyrion”，包含游戏、视觉、Mod 和 Qm 功能。当前为 1.2.0 移植预览版本；已接入组件和完整 Qm 复刻有区别，未完成部分见 [QMCLIENT_PORT.md](QMCLIENT_PORT.md)。

## 三个分身

游戏菜单中逐次点击“连接分身”，可连接主号加三个分身。顶部选择当前控制角色；每个分身旁的 × 仅断开对应连接。各连接保留自己的网络、快照与输入状态，复制动作可同步多个分身；切换时释放原角色的移动和钩子。

## 冻结队友钩救求解

在“游戏 → 钩救求解”启用，选择同队且当前可见的冻结队友后点击“求解”。显示起钩站位 X/Y、角度、鼠标向量及到达路线，仅提供提示，不自动移动或出钩，也不计算如何把队友拉出冻结区。

先搜索可到达的稳定地面站位，未找到可行地面解时才检查空中位置。可绕路走到的位置视为同侧，不按目标左右划分；墙体按 Tee 的 28×28 碰撞箱检查，冻结按中心与中心移动路径判定，允许身体部分探水。

成功结果不会因超时、走偏、自己冻结或队友移动而自动清除。服务器确认原求解角色实际钩中所选队友后自动清除；手动清除、关闭、重选、换图或断线仍可重置。搜索有距离、状态数量与时间限制，不能保证找到地图中的所有可行路线。动态地形或队友移动后可以重新求解。

## Qm 游戏与界面组件

“Qm 功能”中提供武器弹道、小窗、Steam、聊天补全、输入法、动画、模糊、控制台及落水统计的开关与常用参数。

- 武器弹道为辅助显示，可使用 `+showweapontrajectory`。
- Gores 落水统计只在非 0 队伍内记录同队成员，次数以 `[次数] 名字` 显示在 Tab 玩家列表中，移除原浮动榜单。本队收到 teamkill 后清零并重新统计，其他队伍的 teamkill 不影响本队。退出、切换队伍或关闭后清空。
- 分身小窗显示第二视图；Steam 集成包含路径探测、启动和 Rich Presence，需 Steam 正常运行。
- 控制台包含搜索、筛选、选择、导出及外观设置；Windows 输入法使用 Qm 候选窗口与焦点处理。
- 主导航使用 Qm 胶囊滑块、悬停反馈及社区入口动画；设置使用分离式侧栏和原版卡片系统，支持连续入场、折叠展开、拖动排序、全宽切换与高度重排动画。
- 常规、玩家、外观、图形、声音、DDNet、TClient 常规与 Xyrion 设置已按功能拆为卡片。图形页和 Xyrion 的 Qm 功能页可调整动画开关、强度、边框及配色。
- 皮肤、绑定、资源和复杂编辑页面仍保留内部布局，外框使用 Qm 卡片。表情补全、游戏内额外动画及音乐应用专用 Hook 仍未全部完成。

## 像素移动

“设置 → Xyrion → 游戏 → 像素移动”可设置开关按键；“设置 → 控制 → 移动”也有“像素移动开关”。默认不占用任何按键。点击按键框后按下所需键，可用组合键；绑定保存到客户端配置，运行时模式默认关闭。

按开关键切换模式。开启后，原有左右移动键（通常为 A/D）每次按下只发送同方向 1 个游戏 tick（50 Hz 下约 20 毫秒）的短按输入，随后发送松开，按住不连发。未绑定其他命令的 ←/→ 也可使用；已绑定命令的方向键保留原绑定。连续按键最多排队 16 次，每次短按之间至少有 1 个 tick 的松开。

不搜索运动方案、不自动反方向制动，也不修改角色位置或速度。松开后由游戏自然减速，实际距离取决于调参、惯性、地形与服务器处理，不保证正好 1 像素。短按可配合正常跳跃、钩子和开火；切换角色、死亡、打开聊天或菜单时清空待执行动作。设置卡片显示最近状态。

执行时暂时停用 Fast/Best/Cloud 的额外输入预测偏移，关闭模式后恢复原配置效果。本次只编译打包，未进行游戏内实测。

## 动态平衡（下方角色）

在“设置 → Xyrion → 游戏 → 动态平衡”启用并设置开关按键；“设置 → 控制 → 移动”也有“动态平衡开关”（`+teebalance`）。自己作为下方 Tee，在普通地面上使用，附近的目标 Tee 应停稳、可碰撞，距离不超过 384 世界单位。按一次快捷键后自动自然减速停稳，选择最近的合适角色，搜索多个起手间距，并模拟走到站位、钩锤与后续持续方向。完整验证通过后才自动走过去并建立平衡，无需自己对准起手位置。上方队友全程不需要按键。

自动找位通过正常行走及自然减速到达候选站位，不用反方向制动；当前只搜索同一连续地面上的行走路线，不会跳跃绕过障碍。钩锤建立阶段使用朝目标的一侧移动、松开、钩子和最多两次锤击。进入保持阶段后，方向固定为同一侧并一直保持，钩子和锤子松开，不通过断续方向输入维持。默认调参的实测相对横距为 24～25、高差 25 世界单位，中心距离约 35、仰角约 45°。这是两个 Tee 一起缓慢前进的动态平衡，并非原地悬停；需要前方有足够连续地面。

搜索使用当前角色调参、碰撞和强弱顺序；核心搜索在角色当前局部支撑面上检查持续方向 250 tick 的稳定性；保持相对位置和速度演化，消除长距离平移，避免远处墙体使当前可用方案失效。候选另经过完整预测世界复核真实走位、钩锤与建立后的局部收敛，连续 4 tick 达到平衡才允许执行，最多等待 50 tick。该部分仍使用实时算法，不使用预计算动作表。普通计时检查点、喷气能力标记及附近未接触的玩家不会直接否决方案；干扰按实际碰撞或钩子牵引判断，地面自然减速使用当前地图的摩擦调参。搜索左右候选站位，使用更密的起手间距并跳过重复的实际站位；取快照前等待锤子就绪。搜索有深度和状态数量上限，展开与持续方向探测均逐 tick 分帧处理，每帧计算预算约 1 毫秒、单次搜索最多 5 秒，未找到方案时不执行。设置卡片显示最近状态及已验证的距离、高差、角度。再次按快捷键或手动移动、跳跃、出钩、开火即可停止；聊天、菜单、死亡、换图、切换角色、落地支持丢失、危险地形及其他玩家实际碰撞或钩子牵引也会停止。平衡被打破后需要重新启动。

目前仅支持 DDRace 物理及普通可达地面，不支持 FNG、分身动作复制／自动锤击／单独控制并用。启用期间关闭像素移动并暂时停用 Fast/Best/Cloud 的额外输入预测偏移，退出后恢复原有预测配置效果。上方角色的冻结输入不需要解除，但锤子仍按服务器规则产生解冻效果；机关、传送、速度带等复杂场景可能没有可行方案。

2026-10-25 已用真实角色核心测试左右方向、两种处理顺序、强弱模式和三个初始间距，共 24 种组合，每种保持 500 tick；本地服务器中上方连接保持零方向输入，向右持续超过 60 秒，向左建立及手动退出也通过实测。自动找位版另在 320 世界单位初始间距的左右场景验证自动走近、钩锤和保持，墙体阻断路线时放弃执行。网络校正、不同调参和其他角色干预仍可能破坏平衡。

## 灵动岛、封面与歌词

已删除 BestClient 灵动岛，改用固定来源 QmClient 的 HUD 灵动岛布局与原版动画：入场下落与展开弹簧、液态副岛、切歌封面缩放/淡入淡出、文本过渡、播放波形和歌词滚动。时间、队伍、观战人数、交换/开关/禁言倒计时按原版布局整合；空闲时显示本地时间，不绘制空封面。设置 → Xyrion → 视觉中的灵动岛卡片提供相应开关。

Windows MinGW 发布包通过随包 `qm_system_media.ps1` 桥接到系统 SMTC；后台线程采集、解析和解码封面，主线程只上传纹理。歌曲切换保留旧封面供过渡动画使用，支持封面延迟到达与刷新。歌词保留 LRCLIB 匹配来源，使用 Qm 原版 LRC 时间轴和灵动岛显示；查询会发送歌曲元数据。Qm 的网易云/QQ/酷狗/汽水私有 Hook、Spotify 集成和 MSVC 原生 WinRT 后端尚未移植。

计分板右侧使用 Qm 原版媒体控件；解锁计分板鼠标后可切换歌曲与播放/暂停。当前 SMTC 桥接没有会话音量能力，音量控件显示不可用。

## Mod 积木编辑器

管理器支持新建、启用、改名、保存、导入和导出 `.mod` 文件。编辑器提供搜索、拖放、条件、变量、参数、循环、等待、复制与折叠；Ctrl+S 保存。Mod 说明保留在页面中。

“对准最近目标（360°）”“取瞄准处最近目标”及相关示例、扫描逻辑已删除。“获取数值”的目标信息只查询当前瞄准射线。旧文件中的已删除动作会在加载时移除，对应 Mod 停用并提示检查；其余内容可编辑，原文件不会在加载时被覆盖。

Mod 页使用 Qm 共用卡片、按钮、输入框和动画，中性背景与窄类别色条替代原来的大块蓝色填充。

## 内置浏览器

首页及 Xyrion 设置顶部可打开 WebView2 浏览器，默认 F8 切换，原有 F8 绑定保留；控制台命令为 `toggle_browser`。支持地址栏、前进、后退、刷新、拖动、缩放、最小化和保存窗口位置。

浏览器窗口、地址栏、胶囊按钮及操控开关采用 Qm 风格，跟随 Qm 表面、强调色、文本颜色和动画等级设置。Windows 原生宿主将 Qm 主题与动画结果用于窗口绘制，网页本身由 WebView2 渲染。

浏览器显示时按 Alt 在浏览器与游戏之间切换操控。浏览器模式可输入文字、操作网页、拖动及缩放；游戏模式将键鼠完整交回游戏，网页仍保持可见并继续运行，重新按 Alt 可回到浏览器。顶部“返回游戏”及“回到游戏”开关也可切回游戏，F8 隐藏浏览器。缩放使用鼠标捕获与逐帧几何更新，避开 Windows 阻塞式窗口缩放循环；WebView2 的布局与位置通知合并在游戏更新阶段。独占全屏打开浏览器时会切换无边框模式，关闭后恢复。需要 Edge WebView2 Runtime 和同目录 `WebView2Loader.dll`。

## 独立声音开关

设置 → 声音中增加武器、角色、钩子、拾取与提示、聊天、夺旗和菜单音乐卡片，共覆盖 41 类内置声音。每类的随机音频变体共用一个独立开关；关闭立即停止正在播放的该类声音，后续本地、网络、预测与演示播放均通过同一入口过滤。总声音、游戏音效、聊天和音乐等原有总开关仍生效，地图自定义音频继续通过地图音量调整。

自动 AFK fly 已删除，包括组件、物理规划器、设置、快捷键入口和输入接管。

2026-10-30 验证：落水统计与动态平衡共 29 项回归通过；独立本地服务器中按住浏览器边框缩放时游戏仍处理输入与更新，Alt 切换后游戏按键和网页打字互不触发，连续 8 次切换正常，网页心跳持续运行；声音页卡片渲染与独立配置读写通过检查。本次覆盖 `build-xyrion/XyrionClient.exe`，不更新 ZIP。

## 视频背景与移动 quads

菜单背景可选择本地 MP4/H.264 视频，发布包附播放 DLL，视频本身不随包分发。具体说明见 [VIDEO.md](VIDEO.md)。

移动 quads 碰撞预测保留静态几何缓存，共享包络计算，动态对象增量更新空间索引。大量 quads 场景的实际帧率仍受地图、显卡及视频解码影响，未提供统一性能保证。
