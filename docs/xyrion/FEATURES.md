# 功能与当前状态

主要入口为“设置 → Xyrion”，包含游戏、视觉、Mod 和 Qm 功能。当前为 1.2.0 移植预览版本；已接入组件和完整 Qm 复刻有区别，未完成部分见 [QMCLIENT_PORT.md](QMCLIENT_PORT.md)。

## 三个分身

游戏菜单中逐次点击“连接分身”，可连接主号加三个分身。顶部选择当前控制角色；每个分身旁的 × 仅断开对应连接。各连接保留自己的网络、快照与输入状态，复制动作可同步多个分身；切换时释放原角色的移动和钩子。

## 冻结队友钩救求解

在“游戏 → 钩救求解”启用，选择同队且当前可见的冻结队友后点击“求解”。显示起钩站位 X/Y、角度、鼠标向量及到达路线，仅提供提示，不自动移动或出钩，也不计算如何把队友拉出冻结区。

先搜索可到达的稳定地面站位，未找到可行地面解时才检查空中位置。可绕路走到的位置视为同侧，不按目标左右划分；墙体按 Tee 的 28×28 碰撞箱检查，冻结按中心与中心移动路径判定，允许身体部分探水。

成功结果不会因超时、走偏、自己冻结或队友移动而自动清除。服务器确认原求解角色实际钩中所选队友后自动清除；手动清除、关闭、重选、换图或断线仍可重置。搜索有距离、状态数量与时间限制，不能保证找到地图中的所有可行路线。动态地形或队友移动后可以重新求解。

## Qm 游戏与界面组件

“Qm 功能”中提供武器弹道、小窗、Steam、聊天补全、输入法、动画、模糊、控制台及落水统计的开关与常用参数。

- 武器弹道为辅助显示，可使用 `+showweapontrajectory`。
- Gores 落水榜只在非 0 队伍内统计同队成员，退出、切换队伍或关闭后清空。
- 分身小窗显示第二视图；Steam 集成包含路径探测、启动和 Rich Presence，需 Steam 正常运行。
- 控制台包含搜索、筛选、选择、导出及外观设置；Windows 输入法使用 Qm 候选窗口与焦点处理。
- 公共 UI、弹窗、滚动与部分页面动画已迁入。全部设置卡片、页面导航、表情补全及 Qm 原版媒体后端仍未全部完成。

## 灵动岛、封面与歌词

当前仍采用既有的 BestClient 媒体组件及本项目适配，Qm 原版媒体后端尚未完成替换。没有媒体信息时可显示本地时间，不显示空封面。

Windows 发布包通过随包 PowerShell WinRT 桥接读取系统媒体会话及控制播放器；歌曲、进度与封面取决于播放器提供的数据。封面支持延迟重试和更新缓存。歌词使用 LRCLIB 在线匹配，查询会发送歌曲元数据；未匹配时显示歌曲信息。

## Mod 积木编辑器

管理器支持新建、启用、改名、保存、导入和导出 `.mod` 文件。编辑器提供搜索、拖放、条件、变量、参数、循环、等待、复制与折叠；Ctrl+S 保存。Mod 说明保留在页面中。

“对准最近目标（360°）”“取瞄准处最近目标”及相关示例、扫描逻辑已删除。“获取数值”的目标信息只查询当前瞄准射线。旧文件中的已删除动作会在加载时移除，对应 Mod 停用并提示检查；其余内容可编辑，原文件不会在加载时被覆盖。

Mod 页使用 Qm 共用卡片、按钮、输入框和动画，中性背景与窄类别色条替代原来的大块蓝色填充。

## 内置浏览器

首页及 Xyrion 设置顶部可打开 WebView2 浏览器，默认 F8 切换，原有 F8 绑定保留；控制台命令为 `toggle_browser`。支持地址栏、前进、后退、刷新、拖动、缩放、最小化和保存窗口位置。

顶部“操控游戏”开关允许浏览网页时控制游戏，输入文字时关闭游戏控制。独占全屏打开浏览器时会切换无边框模式，关闭后恢复。需要 Edge WebView2 Runtime 和同目录 `WebView2Loader.dll`。

## 视频背景与移动 quads

菜单背景可选择本地 MP4/H.264 视频，发布包附播放 DLL，视频本身不随包分发。具体说明见 [VIDEO.md](VIDEO.md)。

移动 quads 碰撞预测保留静态几何缓存，共享包络计算，动态对象增量更新空间索引。大量 quads 场景的实际帧率仍受地图、显卡及视频解码影响，未提供统一性能保证。

## 其他保留功能

- 中文地图编辑器、Tee 饰品与可选液态玻璃表面。
- 可选自动翻译及 `/fy` 翻译发送，涉及联网服务；失败时按对应功能设置保留或不发送正文。
- 默认关闭的提及触发 AI 回复，接口与密钥在本地填写，详见 [AI.md](AI.md)。
