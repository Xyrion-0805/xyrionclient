# Xyrion client 1.2.0 发布包

## 2026-10-30 更新：客户端与服务端合包

运行包包含最新 `XyrionClient.exe` 和修改版 `DDNet-Server.exe`，以及共用运行依赖、地图资源、服务器示例配置和来源许可。解压后启动对应 exe；服务端配置见根目录 `autoexec_server.cfg`，默认不公开注册。

新增 Envelope Trigger 与 QQuad 联动：`envelope_trigger_spawn pause` 让地图加载时的包络停在起点，Switch 层的 Envelope Trigger Team／Solo 按编号触发单次、循环、暂停、继续与重置；服务端权威碰撞和客户端显示／预测共用播放状态。地图配置与编号示例见 `docs/ENVELOPE_QQUAD.md`。

此包也包含 Demo 剪辑工作台（Demo 片段与 MP4 输出）、编辑器矩形 Slice、浏览器 Alt 焦点切换与缩放修复、41 类独立声音开关、Tab 落水计数与本队 teamkill 重置，以及近期 Qm UI／媒体功能更新。版本号保持 1.2.0；本次已编译，未运行测试或游戏内验证。

本包已用 QmClient 原版 HUD 灵动岛替换 BC 组件，接入液态伸缩、入场弹簧、切歌封面和文本过渡、歌词滚动及计分板媒体控制。Windows 使用后台 SMTC 桥接，保留已有其他功能与修复。复杂设置页内部布局、音乐应用专用 Hook、表情补全仍在移植中，详见 `docs/QMCLIENT_PORT.md`。

新增功能开关位于“设置 → Xyrion → Qm 功能”。Gores 落水统计仅在加入非 0 队伍后启用，只统计同队成员；退出或切换队伍、关闭统计时清空。

本次补齐分身连接按钮及提示的简体／繁体中文，修复 Windows 媒体封面流读取失败、封面延迟出现后不重试的问题。专辑封面更新时会刷新缓存，并支持最大 8 MiB 的封面数据。

移动方块／移动水预测已优化大量 quads 场景：静态碰撞几何保留缓存，同一动画包络及偏移共享计算，动态 quads 仅在跨网格或显隐变化时更新空间索引；点查询减少分配和排序，裁剪复用缓冲区。碰撞处理仍按原图层顺序执行，预测回退时按目标时间更新。此次直接编译打包，未进行游戏内帧率实测。

解压后直接运行 `XyrionClient.exe`。请保持 exe、DLL、`data` 和 `storage.cfg` 在同一个目录中。

## Qm 界面与动画

主导航接入 Qm 胶囊滑块、悬停反馈和收藏社区入口动画。设置采用分离式侧栏，常规、玩家、外观、图形、声音、DDNet、TClient 常规及 Xyrion 功能区接入原版卡片系统，支持连续入场、折叠展开、拖动排序、全宽切换和高度重排。外观预览随卡片滚动并裁剪。

“设置 → 图形 → 界面动画”和“设置 → Xyrion → Qm 功能 → Qm 界面与动画”提供动画选项。皮肤、按键绑定、资源及复杂编辑器目前保留内部列表布局，尚未完整复制其原版内容；游戏内额外动画也尚未全部接入。本次直接覆盖编译打包，未运行自动测试或启动客户端做视觉验收。

## 像素移动

在“设置 → Xyrion → 游戏 → 像素移动”设置开关按键，也可在“设置 → 控制 → 移动”绑定“像素移动开关”。默认关闭且不占用现有按键；按一次绑定键切换模式。开启后，每次按下左右移动键只发送同方向 1 个游戏 tick（约 20 毫秒）的短按，随后松开；按住不会连续触发。未绑定其他功能的左右方向键也可使用，状态在该设置卡片内显示。

已删除自动搜索和反方向制动。位置、速度与自然减速完全由游戏物理处理，实际距离随调参、惯性和地形变化，不保证正好 1 像素。开启期间暂时停用额外输入提前预测，关闭后恢复原设置。本次仅编译打包，未进行游戏内实测。

Tee 自定义眼镜与帽子已移除，包括绘制、配置项和设置入口。

## 动态平衡

在“设置 → Xyrion → 游戏 → 动态平衡”启用并绑定开关键，也可在“设置 → 控制 → 移动”绑定。自己为下方角色，在普通地面按一次快捷键；客户端自然减速停稳，选择 384 世界单位内最近的停稳、可碰撞目标，自动搜索起手位置和可行走路线。完整模拟复核通过后，自动走到位置、钩锤并建立平衡。路线限于连续地面，遇到墙体或危险地形会放弃不可达候选。修复检查点地面、喷气能力标记和未接触旁人的误判；自然停稳使用地图摩擦，失败时显示具体原因。左右搜索采用对称坐标剪枝，增加候选间距和最多两次锤击，等待锤子就绪后再计算；失败搜索按小步分帧执行并限制总时长。稳定性在当前局部地形验证，不再要求长距离前方全部无墙；实际走位、钩锤空间和即时碰撞仍按真实地图检查。上方队友不需要按键。

进入保持阶段后始终按住同一方向，钩子与锤子松开，不断续按方向、不反向制动。两人会一起缓慢前进，前方应有连续地面。默认调参实测横距 24～25、高差 25 世界单位，距离约 35、角度约 45°；最终几何信息在设置卡片显示。

再次按开关键或手动移动、跳跃、出钩、开火可退出。菜单、聊天、死亡、角色切换、地形及其他玩家干扰也会终止；未找到可行方案时不执行。目前仅支持 DDRace 普通地面，使用前关闭分身动作复制、自动锤击和单独控制。已完成 24 种角色核心测试及本地服务器连续保持实测，详细范围见 `docs/FEATURES.md`。

## 冻结队友钩救求解

打开“设置 → Xyrion → 游戏 → 钩救求解”，启用后选择同队、当前快照可见的冻结队友，点击“求解”。结果显示推荐起钩站位 X/Y、鼠标角度和整数瞄准向量；地图显示站位、到达路线与瞄准线。格坐标为世界坐标除以 32，角度为右 0°、下 90°、左 180°、上 270°。自行沿路线到达标记位置后按该角度出钩。

求解只以钩子能否命中目标为目的。地面方案与空中方案严格分轮：先检查搜索范围内通过行走或跳跃能够到达、停稳的全部地面候选；这些候选均无法命中时才检查空中候选。“同侧”按实际行走路线的连通性判断，能够绕路走到的位置也可使用，不再限制目标左右或几何半平面。墙体碰撞使用 Tee 真实的 28×28 碰撞箱；普通／深度／活冻结按角色中心和中心移动路径判定，允许身体部分探入水中，移动水也按中心检测；死亡区单独沿用角色半径三分之一处的四点检测。另检查单向阻挡、调参、玩家遮挡和短时发钩预测，避免推荐墙后或孤立的不可达平台。

到达路径由角色运动物理逐 tick 生成，先尝试行走，再扩展跳跃；空中方案保留到达时的速度和跳跃状态。搜索最多保留 3072 个运动状态，每条路径最多 200 tick，起钩位置在目标钩长范围内且最多距目标 32 格。搜索有限且保守：未知传送出口、需要机关切换、加速带或特殊能力变化的路线不作为可达证明；未找到方案不代表地图中不存在其他路线。不会自动执行移动或出钩。

计算分帧进行，求解过程中若目标、队伍、控制角色或附近玩家明显变化，会取消本次计算以免使用过时状态。成功生成的救援提示没有超时，不会因走偏、自己被冻结、队友解冻或其他玩家移动而自动消失；仅在服务器快照确认原求解角色实际钩中所选队友后自动清除，钩到墙体或其他玩家不会清除。手动清除、重新求解、更换目标、关闭功能、换图和断线仍可重置提示；切换控制分身会保留已有结果。路线按求解时的地形状态计算，对其他玩家未来输入、机关及动态地形的时序不能保证，现场变化后可手动重新求解。本次按要求直接覆盖编译打包，未做游戏内实测。

Xyrion 设置两栏中的功能用法注释已清理，Mod 编辑器与 AI 自动回复部分保留说明；功能开关、参数名和运行状态继续显示。

## Mod 编辑器

移除“对准最近目标（360°）”和“取瞄准处最近目标”动作及“查询并对准”示例，同时删除周围目标扫描逻辑。“获取数值”的目标数据仅来自当前瞄准射线，不再自动寻找附近目标；显式设置角度、事件、变量、条件、循环等其他积木保留。

旧 `.mod` 文件若含已移除动作，加载时仅移除对应积木，并停用该模组、标记为待检查，避免剩余规则直接运行。其余规则仍可编辑；检查后可保存并手动启用，原文件在手动保存前不修改。

Mod 管理器与积木编辑器接入 Qm 共用圆角卡片、按钮、输入框、下拉框和动画。面板及积木使用中性背景与细边框，选中项使用灰白高亮，积木类别仅以窄色条区分，去掉原先成片的蓝色填充；保留 Mod 使用说明。

## 三分身

游戏菜单里逐次点击“连接分身”，可以连接三个分身（主号加分身共四个玩家）。
菜单顶部可以选择主号或分身 1／2／3 控制；每个分身旁的 × 只断开该连接。
分身保留各自的快照与输入状态；开启原有“复制动作”可同步动作。
切换分身时释放原分身的移动和钩子。地图重载会恢复原连接数量和选择。

F1 控制台：`dummy_select 0` 切回主号，`dummy_select 1`／`2`／`3` 切换分身。
`dummy_disconnect 2` 仅断开分身 2，不带编号则全部断开；`dummy_status` 显示连接状态。
可以自行绑定，例如 `bind f6 "dummy_select 2"`。
服务器需要允许同一 IP 的四个连接；本地 0.6 与 0.7 流程已验证。

客户端沿用 DDNet 的用户配置目录：Windows 通常是 `%APPDATA%\DDNet`。第一次运行会自动创建；已有 DDNet/TClient 设置不会被发布包覆盖。

## AI 自动回复

打开“设置 → Xyrion”，开启 AI 自动回复，填写 API 地址、API Key、模型和提示词。API Key 只保存在本机配置中，请不要把配置文件发给别人。

## MP4 背景

在“设置 → Xyrion”中开启视频背景，点击“选择视频…”从 Windows 文件窗口选择视频。发布包已经包含支持 MP4/H.264 的 FFmpeg DLL；视频文件本身不会被打进包里。

## 内置浏览器

点击首页左下方或“设置 → Xyrion”顶部的“内置浏览器”，也可以按默认快捷键 F8。支持网页地址输入、前进／后退、刷新、拖动、缩放、最小化和关闭。已有 F8 绑定会保留，可在“设置 → 控制”修改浏览器快捷键；控制台命令为 `toggle_browser`。

浏览器顶部使用客户端共用的 Qm 主题配色和动画运行时，包含圆角导航、胶囊地址栏、按钮悬停／按下反馈及游戏操控开关过渡。网页内容由 WebView2 渲染；顶部“操控游戏”开关与输入时暂停游戏操控的行为保留。

Windows 需要 Microsoft Edge WebView2 Runtime，exe 同目录的 `WebView2Loader.dll` 已随包提供。独占全屏下打开会暂时切换无边框，关闭后恢复。

## Mod 积木

在“设置 → Mod 管理器”中新建或编辑模组。模组文件保存在用户配置目录的 `mods` 子目录中。

支持规则／积木复制、搜索、展开／折叠、示例模板和 Ctrl+S 保存。

## BestClient 功能与中文编辑器

“设置 → Xyrion”采用双栏分组布局。跑图预测、文字聊天气泡和跑图预测来自 BestClient；顶部灵动岛及其 UI 动画改用 QmClient 原版，默认开启。灵动岛仅在在线游戏画面显示。编辑器中文默认开启且无需开关。完整说明见 `docs/FEATURES.md`，源码来源及适配见 `docs/BESTCLIENT_SOURCE.md`。

路线百分比为地图几何估算。歌曲识别和歌词同步依赖 Windows 媒体信息，歌词使用 LRCLIB 在线查询并通过 Qm 时间轴和灵动岛显示。空闲灵动岛显示时间；空闲图片不显示。旧的自制组件和 UI 调整页已移除。

## 运行要求

- Windows 10/11 64 位
- 支持 OpenGL 的显卡驱动
- 首次运行时允许客户端访问网络，以获取 DDNet 服务器列表；AI 功能只在配置后请求你填写的 API 地址

本包不包含个人设置、聊天记录、API Key、视频文件或源码。

## 地图预览、聊天与玻璃 UI

单击服务器后，地图预览在选中行下方展开；再次单击收起，双击连接。中文指令提示、玩家消息正文自动翻译和全局 UI 液态玻璃均可在 Xyrion 设置中控制。自动翻译跳过服务器消息及玩家名。液态玻璃按 yzrt 示例的分层阴影与高光实现，需桌面 OpenGL 3 或以上，默认关闭。

液态玻璃不透明度在 Xyrion 设置中拖动滑条调整，默认 100%。有色 UI 使用更高的填充不透明度以保留颜色，白色高光只保留在窄边缘。
