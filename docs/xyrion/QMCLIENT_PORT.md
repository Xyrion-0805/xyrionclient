# QmClient 源码迁移（进行中）

来源：<https://github.com/wxj881027/QmClient>，固定提交
`2b626303c0985baf70c9fb599b26a4f35b8ac8c5`。

迁移目标是现有 XyrionClient，沿用来源 UI 与动画实现，不重新设计。
保留浏览器、Best Input、多分身、Mod、视频背景等已有功能。

## 本次可运行包

版本为 1.2.0，包含当前已完成的移植和运行依赖。此包为迁移预览版本，
不代表所有 QmClient 功能已经移植完成。

- 武器弹道组件已接入角色绘制与 `+showweapontrajectory`。
- Steam 路径探测、启动、Rich Presence 已接入，构建启用 STEAM，附真实运行 DLL。
  登录 Steam 后的实际状态更新仍待验收。
- Gores 落水计数已接入快照与原版榜单绘制，地图与连接切换时重置。
- 已接入 QmUi 动画运行时、布局树、公共控件、弹窗、滚动和提示气泡。
  OpenGL 3.3 实现 render target、SDF、模糊与环形渲染。
- Mod 管理器与积木编辑器使用 Qm 共用卡片、按钮、输入框和悬停动画，
  中性背景替代原先的大块蓝色；这不表示全部设置页均已替换。
- 控制台已迁入搜索、筛选、选择、聊天导出、外观设置和配色预览。
- 聊天命令补全面板和交互已迁入；表情补全仍待接入。
- 已接入 Qm 行输入、输入焦点管理与 Windows SDL2 IME 候选窗口。
- 分身小窗已接入地图、角色等第二视图和渲染目标生命周期；
  实际多连接游戏场景仍待验收。
- 已随包附上 Phosphor 四套原版图标字体。
- 修复设置提示气泡首次出现时的文字容器断言闪退：补齐原版
  `RecreateTextContainerSoft` 对尚未创建容器的处理。
- “设置 → Xyrion → Qm 功能”已加入弹道辅助线、分身小窗、Steam 自动启动、
  聊天补全、输入法、动画、模糊、控制台外观及落水统计的开关与常用参数。
- 落水统计仅在 Gores 非 0 队伍内启用，只记录同队成员；退出、切换队伍或
  关闭统计时清空。旧 `qm_gores_drown_board_include_team0` 配置已忽略。
- 主号加三个分身现有独立网络连接、快照确认和输入状态。游戏菜单顶部可
  选择主号／分身 1／2／3，旁边的 × 只断开对应分身。
  切换时松开原分身的移动和钩子；开启复制动作后同步三个分身。
  当前分身断线时保留其他连接，地图重载后恢复连接数量与所选分身。

## 构建与验证记录

目标 Git 基线为 `350187bce77627b5c8893e6fb401372ab46e3163`。
来源代码在此基线上逐步适配，当前完整状态以本仓库提交为准。
`scripts/port_qmclient.py` 为历史一次性迁移工具，不属于构建流程；
对已适配代码重复运行会覆盖后续改动。

统一构建目录：`build-xyrion`，直接覆盖 `XyrionClient.exe`；旧 next 目录合并后移除。
构建方式及依赖固定版本见 [BUILDING.md](BUILDING.md)。
本地构建日志、截图、测试配置与备份位于被忽略的 `tmp/`，不随仓库上传。
回归脚本：`scripts/verify_qm_settings.py`（独立、不保存用户配置）。
历史移植阶段曾记录 392 项自动化测试通过，包含非 0 队伍会话、退队清空、切换队伍和关闭重开统计，
以及三个快照流、快照恢复、乱序分包和独立输入计数。
`scripts/verify_three_dummies.py` 使用独立测试配置和本地服务器，已验证
0.6／0.7 主号加三个真实玩家连接、分别移动、复制动作、切换松钩、单独断开重连、
当前分身被踢后的切换，以及地图重载恢复。日志与结果位于
`tmp/qm-port/three-dummies-06/`、`tmp/qm-port/three-dummies-07/`。
上述为历史记录，不代表之后每次修改都重新运行了这些场景。
最近 Mod UI、钩救算法和源码整理未新增游戏内验收；本地编译通过与
GitHub 手动构建工作流应分别记录，不将尚未执行的 CI 写成已通过。
设置交互截图回归尚未完成，不视作视觉验收通过。
