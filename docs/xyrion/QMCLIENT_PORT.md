## 2026-10-25 灵动岛替换

固定来源仍为 `2b626303c0985baf70c9fb599b26a4f35b8ac8c5`。`hud.cpp` 中的原版灵动岛渲染与所需 helper 拆入 `hud_media_island.cpp`；动画状态和 `hud_media_island_logic.h` 保留来源逻辑。沿用已有 QmUi 动画运行时和 SDF shader，不再注册或编译 BestClient 的音乐组件，旧 BC 配置、坐标迁移与歌词 UI 一并删除。

适配边界：当前无 Qm HUD 编辑器，以原版默认坐标渲染；未引入无关的 rank demo、宠物或跟随角色倒计时。现有三分身结构保持，HUD 交换消息按当前连接归属处理。Windows 继续使用 SMTC，采集、JSON、封面解码在后台，旧封面延迟释放以覆盖切歌动画。歌词来源仍为 LRCLIB，解析和时间轴选择改用 Qm 源码。音乐应用私有 Hook 和 Spotify 不在本次替换范围内。

原版计分板媒体侧栏也已接入：解锁计分板鼠标后可使用上一首、播放/暂停、下一首。MinGW 的标准 SMTC 桥接不提供会话音量能力，原版音量控件显示不可用。

验证：Windows MinGW/OpenGL 3.3 完整客户端编译成功。107 项相关单元测试通过，涵盖灵动岛状态/布局/运动/SDF、LRC 时间轴与此前 6 项动态平衡回归。隔离配置执行并检查 13 个场景：空闲时钟、播放封面、原版媒体侧栏、切歌无封面、延迟封面、暂停、关闭/重启灵动岛、在线歌词、回到时钟、关闭/重启系统媒体、断线菜单。修正计分板字体映射后再次核对媒体图标与启动/播放场景。证据在 `tmp/qm-island-all-tests.log`、`tmp/qm-island-smoke/results-full.json` 和同目录截图。

真实 Windows SMTC helper 的单次读取正常，本机当时没有活动媒体会话；封面、切歌、开关生命周期使用独立子进程媒体夹具验证，未操控用户的播放器。在线歌词使用 LRCLIB 实际匹配并在岛内显示。未验证第三方音乐应用专用 Hook、真实播放器控制和其他图形平台，也未进行帧耗时基准。

追加封面生命周期回归：隐藏 HUD 后换歌并等待 4 秒，再恢复显示，初版触发失效纹理断言。已将旧封面回收改为等待 HUD 当前/退场快照不再引用，关闭后端时先清空 HUD 的歌曲引用；同一场景复测通过并正常退出。修复前后日志见 `tmp/qm-island-lifecycle-before-client.log`、`tmp/qm-island-lifecycle-after.log`，截图为 `tmp/qm-island-smoke/hud_hidden_track_change.png`。
