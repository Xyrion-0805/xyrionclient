# Demo 剪辑工作台

打开一份已结束录制的 Demo，按 Esc 显示播放控制，点击左上角“剪辑工作台”。游戏画面是实时预览，下方是源素材与成片时间轴。源 Demo 不会被修改。

## 编辑

1. 拖动源素材进度条定位，用“入点 I”“出点 O”或 I/O 快捷键标记选区，点击“添加选区”。入出点数字以源 Demo 起点为 0，50 Tick = 1 秒，出点不包含在片段内。
2. 可以添加最多 64 个片段。点击时间轴上的片段选中；拖动中间排序，拖动左右边缘修剪，边界按 Tick 吸附。也可修改入出点后点击“应用裁剪”，或用“前移／后移”精确排序。
3. 在源素材上定位后，点击“分割 S”或按 S，在选中片段内分割。复制、删除及 25%–400% 变速均支持撤销／重做，最多保留 100 步。
4. 点击“预览成片”或按空格按编排顺序播放，再按空格暂停。逗号／句号逐 Tick 定位；Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 撤销或重做。输入文字期间不会触发剪辑快捷键。
5. “放大／缩小／适应”调整时间轴，下面的滚动条移动可视范围。

## 工程和输出

顶部工程名称使用字母、数字、短横线或下划线，最长 60 字符。

- 保存／Ctrl+S：写入客户端存储目录 `demo-projects/<工程名>.xyrion-cut.json`。再次打开相同源 Demo，输入保存的名称后点击“读取”即可恢复片段。源文件路径或 Tick 范围不匹配时拒绝读取。
- 导出 Demo：后台生成 `demos/edits/<工程名>/clip-01.demo` 等独立片段，保留编排顺序。可以选择过滤聊天。每个片段至少要包含两个实际快照，否则提示失败并清理该片段的临时文件。`.demo` 保留原始游戏 Tick，变速属于剪辑工程及视频的播放属性。
- 导出 MP4：按时间轴顺序与速度编码为 `videos/<工程名>.mp4`，使用内置 H.264 编码器，音频使用游戏声音。界面可切换 HUD、聊天、音频、30/60 FPS；CRF 等编码选项沿用客户端视频设置。
- 导出前自动保存工程。目标 Demo 文件夹或视频已经存在时拒绝覆盖，请更换名称。MP4 导出期间按 Esc 取消，已编码的部分保留为 `<工程名>_rendering.mp4`；Demo 取消后保留已完成片段。

这些路径均相对于客户端实际的存储目录；默认沿用 DDNet 存储配置。MP4 分辨率使用当前游戏画面分辨率；导出中改变窗口尺寸会取消并保留已生成部分。Demo 按源文件实际快照裁切，边界可能与输入 Tick 相差一个快照间隔。

当前工作台针对**同一个源 Demo 的多片段编排**。没有照搬 OpenCut 的浏览器框架，也没有实现多源视频轨道、字幕、转场或外部音轨。

## 验证记录

2026-10-30，Windows / OpenGL 本地验证：5 项片段模型测试通过；真实客户端验证鼠标拖动排序和边缘裁剪、工程保存读取、分割变速、撤销重做、预览、三段 Demo 导出及重新打开、已有视频拒绝覆盖、取消后保留部分视频、源文件哈希不变。4 秒 / 30 FPS 的 MP4 为 120 帧，含游戏音轨；源 Demo 片尾接回前段、首片段仅有 1 Tick 的 60 FPS 输出均通过。Demo 的过短片段会明确拒绝。可用 [verify_demo_editor.py](../../scripts/verify_demo_editor.py) 在隔离存储目录复现。

## 诊断命令

`toggle_demo_editor` 打开工作台；`demo_editor_name <名称>` 指定工程名。

`demo_editor <动作> [整数] [整数]` 支持：`add <入点> <出点>`、`select <从0开始的片段序号>`、`trim <入点> <出点>`、`split <Tick>`、`move <序号>`、`speed <百分比>`、`remove`、`undo`、`redo`、`preview`、`save`、`load`、`demo`、`mp4`、`cancel`、`status`。所有 Tick 参数均相对于源 Demo 起点。
